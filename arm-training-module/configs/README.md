# 配置

- `so101_devices.json`：四块 SO-101 控制板的唯一序列号、角色和稳定别名；
- `99-so101.rules`：可安装到 Ubuntu 的最小权限 udev 规则；
- `action_safety.json`：双从臂动作顺序、控制频率及模拟/真实安全参数状态；
- `设备清单.md`：证据、历史信息和现场核验状态；
- `关节活动范围记录.md`：真机标定后填写的安全范围模板。

用于存放可复用、可提交版本控制的配置文件，例如：

- SO-101 主臂和从臂端口映射；
- RGB/深度相机参数；
- 示教数据采集频率、时长和任务描述；
- ACT、Diffusion Policy 等训练参数；
- 真机推理和安全限位参数。

设备私有配置请使用 `*.local.yaml`，该类文件默认不提交 Git。
