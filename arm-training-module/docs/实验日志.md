## 第 3 天：设备与连接关系盘点

- 日期：2026-07-19
- 今日目标：梳理 SO-101 四条机械臂、串口总线和电机 ID，建立设备清单。
- 使用环境/设备：Ubuntu 22.04 VMware 虚拟机；当前无法接触机器人实物。
- 执行命令：`python -m serial.tools.list_ports -v`，并检查 `/dev/ttyUSB*`、`/dev/ttyACM*`、`/dev/ttyCH341USB*`、`/dev/serial/by-id` 和 `/dev/serial/by-path`。
- 修改文件：`configs/设备清单.md`、`docs/待硬件任务清单.md`、`scripts/check_devices.py`。
- 实验结果：代码确认系统包含 LL/LR/FL/FR 四条臂，每条臂配置 STS3215 电机 ID 1～7；Ubuntu 当前仅发现 `/dev/ttyS0`～`/dev/ttyS31`，没有机械臂 USB 串口。
- 遇到的问题：虚拟机从未连接机器人；项目未保存 USB 序列号、VID/PID、物理路径、udev 规则或完整端口映射。
- 原因判断：现有 `/dev/l_left` 等仅是期望逻辑名称，缺少创建这些链接的硬件属性和规则文件。
- 解决办法：先记录全部可确认信息和低可信度推测；待取得硬件后按待办清单逐条识别、贴标、采集属性和核验电机 ID。
- 明日任务：若仍无硬件，先学习 udev 规则结构并设计不含虚假硬件属性的模板；取得硬件后优先完成设备唯一属性采集。

## 第 5 天：机械臂标定准备

- 日期：2026-07-20
- 今日目标：准备四臂标定、标定文件备份、活动范围记录和急停流程。
- 使用环境/设备：现有 LeRobot SO-101 配置；无机器人实物。
- 执行命令：审查 `control_robot.py`、`manipulator.py` 和 `feetech_calibration.py` 的标定流程。
- 修改文件：`scripts/calibration_files.py`、`tests/test_calibration_files.py`、`docs/机械臂标定操作手册.md`、`configs/关节活动范围记录.md`。
- 实验结果：完成无硬件状态检查、JSON 结构校验、SHA-256 备份清单、活动范围模板和急停流程；真实标定保持阻塞。
- 遇到的问题：当前上游 `--control.arms` 只决定删除哪些缓存，连接时仍会为所有缺少缓存的臂启动标定；首次标定不能据此保证单臂隔离。
- 原因判断：标定选择逻辑和机器人连接/自动补全标定逻辑没有完全隔离。
- 解决办法：在取得硬件前不提供自动执行包装器；先使用只读工具准备和校验文件，后续通过隔离配置或代码修复实现真正逐臂标定。
- 明日任务：取得硬件后验证单臂隔离方案；未取得硬件时可设计第 6 天遥操作安全检查，但不执行真机动作。
