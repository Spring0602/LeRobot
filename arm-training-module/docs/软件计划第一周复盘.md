## 动作安全层设计

### 动作格式

动作共 14 个浮点数，顺序固定为：

```text
left_follower:
  shoulder_pan, shoulder_lift, elbow_flex, wrist_flex,
  wrist_roll, wrist_x, gripper

right_follower:
  shoulder_pan, shoulder_lift, elbow_flex, wrist_flex,
  wrist_roll, wrist_x, gripper
```

### 检查项目

- 动作必须是列表或元组；
- 必须恰好包含 14 个值；
- 每个值必须是有限数值，拒绝布尔值、字符串、NaN 和 Inf；
- 检查每个关节的绝对范围；
- 有上一帧时检查单步最大变化量；
- 有时间戳时检查时间严格递增和控制频率；
- 支持左右臂动作拆分与重新拼接；
- 错误信息包含具体索引、数值和拒绝原因。

### 真实模式与模拟模式

`synthetic` 模式使用测试专用范围，只用于自动测试和后续模拟数据：

- 六个旋转关节：测试范围 `[-180, 180]`；
- 夹爪：测试范围 `[0, 100]`；
- 单步最大变化量：测试值 `10`；
- 目标控制频率：`30 Hz`，容差 `±5 Hz`。

这些数值不是机械臂安全参数。

`real` 模式中的绝对范围和单步变化量当前为 `null`。因此：

```text
real hardware output blocked: measured safety limits are missing
```

只有取得硬件并逐臂测量、复核后，才允许填写真实值和解锁输出。

```bash
source "$HOME/lerobot-env/bin/activate"
cd "/mnt/hgfs/engineering_files/arm-training-module"
python scripts/verify_first_week.py
```

该命令依次检查：

1. Python、LeRobot 和依赖环境；
2. 四臂设备配置与 udev 规则；
3. 四个 synthetic 标定夹具；
4. 一条正常 synthetic 双臂动作；
5. 全部单元测试。

命令不会打开串口、访问电机寄存器或发送机械臂动作。
